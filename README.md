# Marketplace Store

A full-stack multi-vendor marketplace built with:

- React
- React Router
- TanStack Query
- Zustand
- Node.js
- Express.js
- MongoDB
- Mongoose

## Features

- User authentication
- Product listing
- Product creation by users
- Admin product approval
- Shopping cart
- User orders
- Seller sales
- Product search
- Categories and tags
- Featured products
- Popular products
- Admin dashboard
